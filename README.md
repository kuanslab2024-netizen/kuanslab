# KUANS LAB 寬私廚官網

這是 KUANS LAB 寬私廚的 GitHub Pages 網站原始碼。

## 首次發布

1. 解壓縮後，將資料夾內的所有檔案（包含 `.github`）上傳到 `kuanslab2024-netizen/kuanslab` 的 `main` 分支。
2. 到 GitHub 專案的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選擇 **GitHub Actions**。
4. 等候 **Actions** 頁面的發布流程完成。
5. 開啟 `https://kuanslab2024-netizen.github.io/kuanslab/`。

日後只要更新 `main` 分支，網站就會自動重新發布。
